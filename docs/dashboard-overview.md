# Dashboard overview

The dashboard is the signed-in home page for work orders. It brings together summary cards, counts by status, and recent activity. The header also provides quick links to create a request (when permitted), open all work orders, or view the signed-in user's queue.

## Summary cards

Each summary card opens Work Order Search with the corresponding filter. The count on a card matches the results for that filter.

| Card | Count | Additional information |
| --- | --- | --- |
| Open work orders | Work orders in Draft, Assigned, or In Progress | Number opened in the last seven days |
| Assigned to me | Open work orders assigned to the signed-in user | Number due today |
| Overdue | Open work orders with a due date before today's date in the church's time zone | Needs attention |
| Completed (30 days) | Work orders completed in the last 30 days | Average days to close, when completion and creation dates are available |

## Work orders by status

The status cards show the count for each status: Draft, Assigned, In Progress, Complete, and Cancelled. Select a card to open Work Order Search filtered to that status.

## Recent activity

The dashboard lists up to ten work orders with the most recent activity. Activity is based on the latest available creation, assignment, or completion date; the list is ordered newest first, with work-order number breaking ties. Each entry shows the work-order number, title, latest activity (Created, Assigned, or Completed) and its date in the church's time zone, followed by the current status. Select the work-order number to open its details.

When there is no dated activity, the dashboard displays “No work order activity yet.”
