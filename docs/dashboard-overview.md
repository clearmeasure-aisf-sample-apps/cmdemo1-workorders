# Dashboard overview

The dashboard gives signed-in users a quick view of work order volume and recent changes. Use the links on a summary card to open Work Order Search with that card's filter.

## Summary cards

- **Open work orders** counts open work orders and notes how many were opened this week.
- **Assigned to me** counts open work orders assigned to the signed-in user and notes how many are due today.
- **Overdue** counts open work orders past their due date.
- **Completed (30 days)** counts work orders completed in the last 30 days and shows the average time to close. When there are no recent closures, the card says so.

## Work orders by status

Status cards show the number of work orders in each status. Select a card to open Work Order Search filtered to that status.

## Recent activity

The recent activity list shows up to ten work orders, newest activity first. Each entry includes the work order number, title, latest activity date and description, and current status. Select a work order number to open its details. When there is no activity, the dashboard displays a message instead of an empty list.
