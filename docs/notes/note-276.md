# Note 276

`Employee.DisplayName` in `src/Core/Model/Employee.cs` returns the trimmed first name, a space, and the trimmed last name when both names are set (`return $"{FirstName.Trim()} {LastName.Trim()}";`). When only the first name is set, it returns that name trimmed (`return FirstName.Trim();`). When the first name is null, empty, or whitespace, it returns the trimmed last name if that name is set, and `UserName` otherwise (`return hasLast ? LastName.Trim() : UserName;`). A whitespace-only name counts as empty. The middle name is omitted. The same fact is stated in `docs/notes/note-109.md`.
