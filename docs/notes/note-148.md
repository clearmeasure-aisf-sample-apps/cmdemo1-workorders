# Note 148

WorkOrderActivity.Latest returns the latest of the work order's completed, assigned, and created dates, or null when all three are null. The activity is a `WorkOrderActivity(WorkOrderActivityKind Kind, DateTime WhenUtc)` record (`src/Core/Services/WorkOrderActivity.cs`). The kind is the `WorkOrderActivityKind` enum (`src/Core/Services/WorkOrderActivityKind.cs`) with members Created = 1, Assigned = 2, Completed = 3, explicit values in tie-break order. The candidates are the three kinds paired with their dates (`Candidate(WorkOrderActivityKind.Completed, workOrder.CompletedDate)`, etc.), ordered `WhenUtc` descending with `ThenByDescending(a => a.Kind)` as the tie-break, so equal dates prefer Completed over Assigned and Assigned over Created, and the comparison is the enum itself. The person-facing text lives with the kind: `WorkOrderActivityKindText.DisplayName(kind)` (`src/Core/Services/WorkOrderActivityKindText.cs`) returns "Created", "Assigned" or "Completed", which the dashboard prints (`Index.razor.cs` uses `WorkOrderActivityKindText.DisplayName(activity.Kind)`). The method is `WorkOrderActivity.Latest` in `src/Core/Services/WorkOrderActivity.cs`.
