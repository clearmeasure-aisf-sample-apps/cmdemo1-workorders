# Note 148

WorkOrderActivity.Latest returns the latest of the work order's completed, assigned, and created dates, or null when all three are null. The candidates are Completed, Assigned, and Created (`Candidate(CompletedVerb, workOrder.CompletedDate)`, `Candidate(AssignedVerb, workOrder.AssignedDate)`, `Candidate(CreatedVerb, workOrder.CreatedDate)`), ordered `WhenUtc` descending with `Precedence(Verb)` (Completed 3, Assigned 2, Created 1) as the tie-break, so equal dates prefer Completed over Assigned and Assigned over Created. The tie-break is an explicit value: it does not depend on candidate array order or on undocumented `MaxBy` tie semantics. The method is `WorkOrderActivity.Latest` in `src/Core/Services/WorkOrderActivity.cs`.
