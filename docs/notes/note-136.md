# Note 136

DraftToAssignedCommand.Name is the string constant "Assign" (`public const string Name = "Assign";`). TransitionVerbPastTense is "Assigned". GetBeginStatus returns WorkOrderStatus.Draft and GetEndStatus returns WorkOrderStatus.Assigned. UserCanExecute returns true only when the current user is the work order's creator (`return currentUser == WorkOrder.Creator;`). Execute sets WorkOrder.AssignedDate to the context's current date and time, then calls base.Execute. When the assignee has a role whose name is Roles.Bot ("Bot"), Execute sets StateTransitionEvent to a new WorkOrderAssignedToBotEvent with the work order number (or an empty string when the number is null) and the assignee id. The command is DraftToAssignedCommand in `src/Core/Model/StateCommands/DraftToAssignedCommand.cs`. Roles.Bot is `"Bot"` in `src/Core/Model/Constants/Roles.cs`. The same transition is described in `docs/cursor/assignment.md`.
