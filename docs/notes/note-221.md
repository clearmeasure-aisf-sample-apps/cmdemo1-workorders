# Note 221

`WebServiceApiRoutes.AbstractPathSegment` in `src/UI.Shared/ApiHttpContracts.cs` is the constant `blazor-wasm-single-api` (`public const string AbstractPathSegment = "blazor-wasm-single-api";`). `WebServiceApiRoutes.LegacyRelativeUrl` is `api/` plus that segment (`public const string LegacyRelativeUrl = "api/" + AbstractPathSegment;`). `PublisherGateway.ApiRelativeUrl` in `src/UI/Client/PublisherGateway.cs` equals `WebServiceApiRoutes.LegacyRelativeUrl`, and `PublisherGateway.ApiRelativeUrlV1` is `"api/v1.0/" + WebServiceApiRoutes.AbstractPathSegment`. `SingleApiController` in `src/UI/Server/Controllers/SingleApiController.cs` routes the unversioned path at `WebServiceApiRoutes.LegacyRelativeUrl` and the versioned path at `ApiRoutes.VersionedApiPrefix` plus `/` plus `WebServiceApiRoutes.AbstractPathSegment` (`[Route(WebServiceApiRoutes.LegacyRelativeUrl)]` and `[Route($"{ApiRoutes.VersionedApiPrefix}/{WebServiceApiRoutes.AbstractPathSegment}")]`). `docs/conventions/cqrs-request-flow.md` states that the client posts JSON to `api/blazor-wasm-single-api` and that the controller also exposes `api/v1.0/blazor-wasm-single-api`.
