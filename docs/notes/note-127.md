# Note 127

InProgressToCancelledCommand.Name is the string constant "Cancel" (`public const string Name = "Cancel";`). TransitionVerbPastTense is "Cancelled". GetBeginStatus returns WorkOrderStatus.InProgress and GetEndStatus returns WorkOrderStatus.Cancelled. UserCanExecute returns true only when the current user is the work order's creator. IsAllowedInCurrentState returns true only when WorkOrder.WaitingOnVendorSince is null. Execute sets AssignedDate and Assignee to null, then calls base.Execute. The command is InProgressToCancelledCommand in `src/Core/Model/StateCommands/InProgressToCancelledCommand.cs`.
