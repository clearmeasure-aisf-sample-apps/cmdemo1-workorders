# Note 153

DueDateUrgencyCalculator.Calculate(DateOnly? dueDate, WorkOrderStatus status, TimeProvider timeProvider) throws ArgumentNullException when status or timeProvider is null (`ArgumentNullException.ThrowIfNull(status)` and `ArgumentNullException.ThrowIfNull(timeProvider)`). A null dueDate returns DueDateUrgency.None (`if (dueDate is null)` then `return DueDateUrgency.None`). A status other than Draft, Assigned, or InProgress returns DueDateUrgency.None (`if (!IsOpen(status))` then `return DueDateUrgency.None`; IsOpen is `status == WorkOrderStatus.Draft || status == WorkOrderStatus.Assigned || status == WorkOrderStatus.InProgress`). Otherwise it sets today from ChurchTimeZone.Today(timeProvider) (`var today = ChurchTimeZone.Today(timeProvider)`) and returns DueDateUrgency.DueToday when `dueDate.Value == today`, DueDateUrgency.Overdue when `dueDate.Value < today`, and DueDateUrgency.None when the due date is later. The summary comment is "Returns urgency for an editable due date and work-order status relative to Chicago "today"." The method is `DueDateUrgencyCalculator.Calculate` in `src/Core/Services/DueDateUrgencyCalculator.cs`.
