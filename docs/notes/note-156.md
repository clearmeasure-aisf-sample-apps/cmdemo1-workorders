# Note 156

SlaHealth.CalculateOnTimePercentage keeps orders that have both a DueDate and a CompletedDate (`wo is { DueDate: not null, CompletedDate: not null }`). When none qualify it returns `(null, 0)`. Otherwise on time means `ChurchDate(wo.CompletedDate!.Value) <= wo.DueDate!.Value`, and the percentage is `(decimal)onTimeCount / qualifying.Count * 100` rounded with `Math.Round(percentage, 0)`, returned with `qualifying.Count`. The summary comment is "Computes the on-time percentage (0–100, rounded to a whole number) for the given orders. Orders without a DueDate or CompletedDate are excluded. On time means the church-local completion date is on or before the DueDate. Returns a null percentage when no qualifying orders exist." The method is `SlaHealth.CalculateOnTimePercentage` in `src/Core/Queries/SlaHealth.cs`.
