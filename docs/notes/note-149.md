# Note 149

WorkOrderCommandButtons.CssClass returns `btn-app btn-app--danger` when `command.Role` is `CommandRole.Destructive`, `btn-app btn-app--primary` when `command.Role` is `CommandRole.Forward`, and `btn-app btn-app--secondary` otherwise (`CommandRole.Forward => "btn-app btn-app--primary"`, `CommandRole.Destructive => "btn-app btn-app--danger"`, `_ => "btn-app btn-app--secondary"`). Forward roles are Assign, Begin, and Complete; Destructive roles are the Cancel commands that end in Cancelled. The method is `WorkOrderCommandButtons.CssClass` in `src/UI.Shared/Models/WorkOrderCommandButtons.cs`.
