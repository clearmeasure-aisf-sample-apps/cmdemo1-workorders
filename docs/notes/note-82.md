# Note 82

POST `/api/tools/hash` adds lowercase-hex `md5` only when `includeMd5` is true (the query flag when present, otherwise `HashRequest.IncludeMd5`, which defaults to false) and lowercase-hex `sha1` only when `includeSha1` is true the same way. `ToolsHashController.Post` in `src/UI/Api/Controllers/ToolsHashController.cs` sets `wantMd5` from `includeMd5 ?? request.IncludeMd5` and `wantSha1` from `includeSha1 ?? request.IncludeSha1`, then includes `ToLowerHex` of `MD5.HashData` or `SHA1.HashData` only for a requested algorithm. `HashResponse` omits `Md5` and `Sha1` when they are null (`JsonIgnoreCondition.WhenWritingNull`). `docs/api/tools.md` states that optional `includeMd5` and `includeSha1`, in the body or as query flags, add `md5` and `sha1`, and that those properties are omitted when not requested.
