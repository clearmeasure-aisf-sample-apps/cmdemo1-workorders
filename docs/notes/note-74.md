# Note 74

`FeatureFlagNames.ShowPriorityBadges` in `src/Core/FeatureFlags/FeatureFlagNames.cs` is the constant `ShowPriorityBadges`. `src/UI/Server/appsettings.json` sets `FeatureFlags:ShowPriorityBadges` to true. GET `/api/features/flags` and GET `/api/v1.0/features/flags` return the runtime map as JSON. `FeatureFlagsController.Get` in `src/UI/Api/Controllers/FeatureFlagsController.cs` sends `FeatureFlagsQuery` and returns `ConditionalGetEtag.JsonContent(result.Flags)`. The versioned route is `api/v{version:apiVersion}/features/flags` with API version 1.0. `docs/ops/feature-flags.md` lists `ShowPriorityBadges` as true.
