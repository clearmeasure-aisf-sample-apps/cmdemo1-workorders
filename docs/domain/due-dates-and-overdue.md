# Due Dates and Overdue Work Orders

The overdue search filter matches work orders whose due date is before today in the church's America/Chicago time zone. It includes only open work orders: Draft, Assigned, and In Progress. A work order due today is not overdue; work orders without a due date and work orders in terminal statuses are not included.

The Overdue summary card counts work orders using the same overdue predicate as the search filter. Selecting the card applies that filter, so its count matches the resulting search total.
