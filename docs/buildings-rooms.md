# Buildings and Rooms

Work orders can include optional location details to help identify where work is needed:

- **Building** — the name of the building where the work takes place, such as “Sanctuary.” Leave it blank when the location is not associated with a building or is unknown.
- **Room number** — the room or other specific area where the work is needed, such as “204” or “Main kitchen.” Leave it blank when a more specific location is not known or does not apply.

Building and room number are independent fields. A work order can have either, both, or neither. For example, a work order for a common area might have a building but no room number.
