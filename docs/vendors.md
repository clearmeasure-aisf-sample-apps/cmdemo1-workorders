# Vendors

A vendor is an outside company or tradesperson hired for maintenance work. Vendor records can include:

| Field | Details |
| --- | --- |
| Name | Required, up to 100 characters, and unique without regard to case. |
| Trade | Optional; for example, HVAC or plumbing. Up to 100 characters. |
| Contact name | Optional. Up to 100 characters. |
| Email address | Optional. Up to 255 characters; when supplied, it must be a valid email address. |
| Phone number | Optional. Up to 50 characters; when supplied, it must contain at least seven digits and may use digits, `+`, `-`, `.`, parentheses, and spaces. |
| Notes | Optional additional information about the vendor, up to 1,000 characters. |
| Active | New vendors are active. Mark a vendor inactive when it is no longer used. |

Email addresses and phone numbers may be left blank. A nonblank value is validated when the vendor is created.
