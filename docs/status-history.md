# Work Order Status History

The **Status Change History** section on a work order shows recorded changes to its status. Each entry lists the date and time in the America/Chicago time zone, the previous status, the new status, and the employee who made the change. Entries appear newest first.

When no status changes have been recorded, the section displays “No status changes recorded.”

Only actual status transitions are recorded. Changes to other work order details, and actions that do not change the status, do not add history entries.
