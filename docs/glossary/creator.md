# Creator

**Creator** is the employee who created a work order, stored on `WorkOrder.Creator` and set by `WorkOrderBuilder.CreateNewWorkOrder` when the work order starts in Draft (`WorkOrder` in [`src/Core/Model/WorkOrder.cs`](../../src/Core/Model/WorkOrder.cs); [`src/Core/Services/Impl/WorkOrderBuilder.cs`](../../src/Core/Services/Impl/WorkOrderBuilder.cs)). The work-order page shows that employee's display name under the Creator label ([`src/UI.Shared/Pages/WorkOrderManage.razor`](../../src/UI.Shared/Pages/WorkOrderManage.razor)). The creator can save or assign a draft and can cancel from Assigned or InProgress, and is not the assignee; search can filter by creator ([Work order lifecycle](../domain/work-order-lifecycle.md), [Work order search](../work-order-search.md)).
