# Mediator (formerly MediatR)

**Mediator** ([martinothamar/Mediator](https://github.com/martinothamar/Mediator), MIT) is the source-generated library this application uses to dispatch a request to its handler; it replaced MediatR so the hosts can run under Native AOT. At build time its generator finds every handler and writes the `IMediator` implementation and the DI registrations, so a request with no handler is a build error and nothing is resolved by reflection. Handlers return `ValueTask`, and each message is routed to a handler for its exact type. [`IBus`](../../src/Core/IBus.cs) in `src/Core` sends `IRequest<TResponse>` values and publishes `INotification` values; [`Bus`](../../src/UI.Shared/Bus.cs) in `src/UI.Shared` calls `IMediator.Send` and `IMediator.Publish`, and handlers such as [`WorkOrderQueryHandler`](../../src/DataAccess/Handlers/WorkOrderQueryHandler.cs) in `src/DataAccess/Handlers` implement `IRequestHandler`. The path is described in [CQRS request flow](../conventions/cqrs-request-flow.md).
