# Playwright

**Playwright** is the browser automation library this application's acceptance tests use to exercise the whole application in a browser. [`ServerFixture`](../../src/AcceptanceTests/ServerFixture.cs) creates a shared `IPlaywright`, and [`AcceptanceTestBase`](../../src/AcceptanceTests/AcceptanceTestBase.cs) launches Chromium from that instance (package `microsoft.playwright.nunit` 1.61.0 in [`AcceptanceTests.csproj`](../../src/AcceptanceTests/AcceptanceTests.csproj)). [Acceptance tests](../../src/AcceptanceTests/README.md) describes the suite as Playwright and NUnit tests of the whole application in a browser.
