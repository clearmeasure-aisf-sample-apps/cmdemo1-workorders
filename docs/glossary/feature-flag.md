# Feature flag

**Feature flag** is a named on/off value held in the in-memory catalog `FeatureFlagsCatalog` ([`src/UI/Api/FeatureFlagsCatalog.cs`](../../src/UI/Api/FeatureFlagsCatalog.cs)), where `SampleFeatureA` is enabled, `SampleFeatureB` is disabled, and `ShowPriorityBadges` is enabled. `GET /api/features/flags` and `GET /api/v1.0/features/flags` return that map ([`FeatureFlagsController`](../../src/UI/Api/Controllers/FeatureFlagsController.cs)), and the Blazor client reads the flags through `IFeatureFlags` ([`src/UI.Shared/Services/IFeatureFlags.cs`](../../src/UI.Shared/Services/IFeatureFlags.cs), [`HttpFeatureFlags`](../../src/UI/Client/HttpFeatureFlags.cs)). When `ShowPriorityBadges` is enabled, a High-priority work order shows a colored badge on the search list and the board ([Feature flags](../ops/feature-flags.md)).
