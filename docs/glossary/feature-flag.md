# Feature flag

**Feature flag** is a named on/off value from the fixed catalog `FeatureFlagNames` ([`src/Core/FeatureFlags/FeatureFlagNames.cs`](../../src/Core/FeatureFlags/FeatureFlagNames.cs)), evaluated at runtime by [`RuntimeFeatureFlagEvaluator`](../../src/DataAccess/FeatureFlags/RuntimeFeatureFlagEvaluator.cs) from Octopus Feature Toggles, then the `FeatureFlags` configuration section, then false. A request marked `[RequiresFeature]` is rejected by [`FeatureFlagBehavior`](../../src/UI.Shared/FeatureFlagBehavior.cs) on the bus when its flag is off. `FeatureFlagsQuery` returns every value; `GET /api/features/flags` ([`FeatureFlagsController`](../../src/UI/Api/Controllers/FeatureFlagsController.cs)) and the Blazor client's `IFeatureFlags` ([`BusFeatureFlags`](../../src/UI.Shared/Services/BusFeatureFlags.cs)) read it. When `ShowPriorityBadges` is enabled, a High-priority work order shows a colored badge on the search list and the board ([Feature flags](../feature-flags.md)).
