# Token trial a3r

This page lists the board's Status columns and what each one produces.

| Column | Produces |
| --- | --- |
| Todo | an unstarted work item on the board |
| In Progress | active design or implementation work |
| Review | a pull request with required checks |
| Merged | a merge commit on master awaiting deploy |
| TDD | a deploy of that commit to tdd |
| UAT | a promotion of that release to uat |
| Done | a prod deploy, or a docs-only merge |

See [board columns](board-columns.md).
